# Archives

Covers: The archives page.
See also: [content-editor.md](content-editor.md), [game-data.md](game-data.md).

      - `archives` `/archives` (`src/views/ArchivesView.vue`, `src/archive.ts`, added 2026-10-31 at the developer's request, like COMP/CON's compendium): every manufacturer, licence, core bonus, frame, mech weapon, mech system, pilot gear, biomod and talent in the loaded packs (biomods come from the site's own `bionics` table, retired ones left out). A row of underline tabs (`SheetTabs.vue` with each category's count) picks the category; it stays on one row, sticky under the top bar (`--topbar-h`), scrolling sideways with a fade cue (keeping the chosen one in sight), the wheel and end chevrons (`SheetTabs.vue`) when narrow. **Styled by corporation** (2026-10-31): each manufacturer's accent is the packs' `dark` colour (GMS red, IPS-N blue, SSC gold, HORUS green, HA purple; `makerColour()` only accepts a plain hex value, else lilac); logos via `makerLogo()` (the packs' `logo` name, matched against the bundled files, else the manufacturer's id lowercased, so NHC (Nidhogg Collective) gets `nhc.svg`; other homebrew manufacturers have none). Mottos show only their first line (`RulesText` `first-line-only`, `firstLine()` in `rulesText.ts`), so two-line pack quotes such as NHC's read like the others. **Landing:** big manufacturer cards in centred rows (the pre-redesign look, restored at the developer's request on 2026-11-16): a 4px top border in the maker's colour and a tinted body; a tinted header with the large logo stacked above the large code in its colour (opens its information, kept in the url) and the full name; the motto (HORUS, which has no separate full name, shows a glitching "CONGRATULATIONS, PILOT." and the motto "Access is yours, so long as you can keep it."; GMS's two-line pack quote is replaced by "From Cradle to the stars: GMS."; `SUBTITLES` / `GLITCHED` / `MOTTOS` in the view); then one row per category at the card's foot (like the content page's counts: a thin rule above each, in the header border's tone, the first too): the category's name in uppercase in the maker's colour at the left and the count in bold mono at the right. A row is a button that opens that category filtered to the maker (`?cat=` and `?maker=`, so the count matches the list); hover turns the name lilac with the site's faint lilac tint. A zero looks the same but is a plain row, not a button (nothing to open). Every card shows the same rows (licences, frames, mech weapons, mech systems, weapon mods, core bonuses), zeros included ("0 licences" for GMS, "0 weapon mods" for NHC), for consistency. **Categories: a list + detail pane** (2026-11-16, like COMP/CON's compendium). The list is grouped as `archiveGroups()` gives it: a box per manufacturer (its colour only as the logo and a 3px top border; the code and count in the header; manufacturers' order, then unknown sources, then "other", then **Exotic**: group `EXOTIC` (`EXOTIC_MAKER`, neutral, no logo, filter chip too) always last, and Exotic-tagged entries (`ArchiveEntry.exotic`) last within their group), pilot gear one per type, talents one untitled box; mech weapons and systems have a sub-heading per licence ("Barbarossa licence", "No licence"), rows by rank. Each row is a real button: the name and one or two key facts under it (`listFacts()` in `archive.ts`: a weapon's rank and mount and type, a system's rank and SP, a frame's or licence's role, a manufacturer's code). Frames never show a licence rank (every licensed frame comes at rank II, so their information says `Licence: Tortuga` and the frame picker has no rank chip; 2026-11-21). A licence's ranks list their unlocks as coloured bars by type (`UnlockList.vue` `cards`). **Desktop (over 56rem):** the list (22rem) on the left and the chosen entry's full information on the right (its maker's logo, kind and name, then `InfoBody.vue`, the dialog's body), both sticky under the top bar and the tabs and scrolling on their own. The chosen row is lilac with a bar (`aria-current`); it's `?item=`, else the first listed (also when the linked one is filtered out); a linked row is scrolled into the list's view. Arrow keys move up and down the list, choosing as they go (the lore page shares this and the scrolling through `useListPane()` in `src/listPane.ts`, and the list's styles under `.list-pane` in `style.css`). **Phones:** the list only; tapping an entry opens the information dialog. **Search** (`Clear` button, Escape clears too) spans every category (every word must appear in the name, facts or rules text, including the maker code: "horus goblin"), best first: exact name, name starts with it, name contains it, then other text (`searchArchive()`). While searching, the bar shows match counts and an extra first option `all` (results per category under a left-aligned heading with its count, boxes ordered by best match); choosing a category shows its matches in the normal layout. A search typed on the landing goes to `all`, one typed in a category stays in it; clearing returns. **Manufacturer filter:** toggle chips (logo and code in the maker's colour, `aria-pressed`) for the makers in the current view, multi-select, none = all; pilot gear and talents ignore it. **Url state:** `?cat=` (none means the landing, or `all` while searching), `?q=`, `?maker=GMS,IPS-N` (unknown ids ignored) and `?item=<category>:<id>` for the chosen entry (category needed: a licence shares its frame's id): in the pane on desktop, otherwise opened in the dialog once its catalogue loads; dropped when unknown or when the dialog closes; all with `router.replace`, so reloads and shared links keep them. The catalogues don't report when they've finished loading, so with no content at all the page says "No content yet.". **Biomods** (2026-11-19, tab after Pilot gear; the content editor's Biomods list is grouped the same way through `archiveGroups()`: a box per manufacturer with its logo and a 3px top border, Other, then Exotic last, `New biomod` above the boxes): listed by manufacturer like weapons and systems (a box per manufacturer, unknown sources such as EXOTIC, then "Other" for none), rows "Eyes · 1 mod point", the pane is `bionicInfo()`, the maker filter applies, search covers name, slot, effect and description, `?item=biomods:<id>`; every manufacturer card has a Biomods row after Weapon mods. Weapons and systems are the pickable ones (integrated and talent-only items appear in their frame's or talent's information). Manufacturers load from `content_items` kind `manufacturers` (the local seed, `supabase/seeds/lancer-core.sql`, includes the five core ones). GMS's Sagarmatha and Chomolungma frames aren't in core `lancer-data` (any version): Sagarmatha is in `@massif/wallflower-data` and Chomolungma in `@massif/osr-data`, so they appear once those packs are imported. The home page has an archives button too. Tested in `src/archive.test.ts` and `src/info.test.ts`.
