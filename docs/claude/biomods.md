# Biomods

Covers: Biomods (bionics): the site-owned content that raises pilot stats.
See also: [levelling-and-manna.md](levelling-and-manna.md), [content-editor-forms.md](content-editor-forms.md).

- **Bionics / enhancements raise pilot stats.** Decided: they're the **site's own content**, not LCP content. They're stored in Supabase next to the list of custom pilot stats.
  - Each bionic has a name, a description, the stat bonuses it gives, a **manna cost** and a **mod-point cost**. A bonus can only point at a stat that exists in the list. Since 2026-11-18 (migration `20261118120000_biomod_slot_effect_price.sql`, on the hosted project): `manna_cost` is the biomod's real price (`mannaSpent(sheet, bionicPrices)`, `bionicPrices` from `useGameData()`; an unknown id costs 0; changing a price moves the balance of pilots who have it), plus a `slot` (where on the body: free text with suggestions, `BIONIC_SLOTS`; empty is a warning) and an `effect` (rules-text HTML). Since 2026-11-19 (migration `20261119090000_biomod_manufacturer.sql`, on the hosted project) a biomod has a **manufacturer**: `bionics.source`, the id of one of the packs' manufacturers (null = none, listed under "Other"; `save_bionic` takes it as a last argument, `new_source`). A HORUS, NHC or Exotic biomod is **GM edit only** for everyone, GMs and owners included (the developer, 2026-11-19; `bionicOptions` in `PilotManageView.vue` folds HORUS/NHC into the Exotic rule for biomods only; reason "GM edit only") (see "The Exotic Gear tag" in [content-editor-forms.md](content-editor-forms.md)); biomods have no tags. Owners create and edit them in the content editor (`BionicForm.vue`: name, slot, manufacturer (the same option list as the item forms; empty is a warning), price, mod points, stat bonuses, description, effect). The editor tab and every visible label say "biomods". Cards and the information show the slot and price in the facts line, the effect as rules, and the description as flavour (dim, italic, like lore).
  - **Mod points:** installed bionics can't cost more than the pilot's mod limit, which is 6 + level (homebrew, see [levelling-and-manna.md](levelling-and-manna.md)). The sheet shows points used against the limit.
  - Installing a bionic is a normal pending change: add the bionic and pay the manna. Once installed, a bionic can only be swapped for a similar one. That rule isn't coded; GMs judge it when approving.
  - Bionics are public, like the rest of the sheet (2026-11-19).
  - Characters store bionic IDs, like any other item. Only owners can add or change bionics, and stats (stats only in the Supabase dashboard: the content editor no longer edits them). One that's in use can't be deleted.
  - To start, owners can add them in the Supabase dashboard's table editor. Anyone with dashboard access can change *everything*, so only trusted people get it. An owner-only form in the site can come later.
  - Why not LCP: `cc-lcp-editor` has no bonus that targets a specific stat, reusing an existing bonus ID would clash with official items, and a custom ID would have to be typed into the JSON by hand.
