# Backstory

Covers: The backstory: private by default, optionally public.
See also: [pilots.md](pilots.md), [dossier-page.md](dossier-page.md).

- **Background:** a backstory the player writes as free text. LANCER's ready-made backgrounds aren't used. **Private by default; the player can make it public** (the developer, 2026-11-19), the only part of a pilot that is private from other players, and the only section whose privacy is shown and toggled.
  - **Storage:** the backstory stays in the private sheet (`sheet.backstory`). RLS is whole-row, so a public copy lives in its own table, `pilot_public_backstory` (`character_id` primary key cascading from `characters`, `backstory jsonb`, `updated_at`), readable by every logged-in user, with **no direct writes for anyone**. **A row exists only while the backstory is public.** Migration `20261119190000_public_backstory.sql`, tested in `supabase/tests/public_backstory.test.sql`.
  - **`set_backstory_public(target_character_id, make_public)`:** `security definer`, callable by the character's own player or a GM or owner, any status. `true` upserts the row from the current `character_sheets.sheet->'backstory'`, `false` deletes it. It touches neither `characters` nor `character_sheets`, so their `updated_at` and the "changed since" approval check don't move.
  - **Following the sheet:** an after-insert-or-update-of-`sheet` trigger on `character_sheets` (`private.sync_public_backstory()`) refreshes an existing public row from the new sheet. So the public copy is the pilot's real sheet (a pending pilot's live edits, an approved pilot's approved backstory after a change is approved) and never an unapproved draft change; a player with a draft change open sees their draft in the editor but others still read the approved text.
  - **Page** (`src/backstory.ts` `useBackstoryVisibility()`, `BackstoryVisibility.vue`, in `SheetField`'s `head` slot): the Backstory panel's head has a Private | Public segmented control (real buttons with `aria-pressed`, a lock on Private) that saves at once with its own `SaveStatus` and works in every status (a submitted pilot too); while public a dim line says "Everyone logged in can read this." The pilot's own player and GM edit mode can change it; GMs and owners on records they can't edit, and the player on a record opened through the registry, see the state read-only ("Private" with the lock, or "Public"). Viewers who can't read the whole sheet row (`canSeeBackstory` false: other players) see a Backstory panel only when a public copy exists (`RichText`).
