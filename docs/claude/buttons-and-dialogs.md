# Buttons and dialogs

Covers: Shared CSS pieces, buttons and the Are you sure? dialog.
See also: [ui-principles.md](ui-principles.md), [pickers-and-info.md](pickers-and-info.md).

  - **Shared pieces** (`src/style.css`, from the prototype): `.panel` (a page section: `--panel` fill, thin border, radius) with `.panel-head` (left-aligned); `.panel.danger-zone` (an irreversible action: faint red border, a sentence in `.danger-body` and a `.danger` button, any error a `.notice.warn` under it; pilot sheet, mech page, lore editor, GM review); `.notice` (a banner with its symbol drawn by CSS: `.info` default, `.warn` danger with a warning sign, `.ok` with a tick; `.notice-head`, `.notice-title`); `.badge` (a pill: `.draft` dashed, `.pending`, `.approved`, `.rejected`, `.dead`, each with its symbol by CSS; a badge with no status is plain); `.chip` / `.chips` (square neutral tag chips); `.sep` (a dot-separated line); `.empty` (the one dashed empty state); `.meter` / `.meter-inline` (budgets; `.full`, `.over`); `.table`; `label.field` (an uppercase label over a control); `.private` (a lock and a word, "GM only" or "Owner only", beside a section heading; no longer used for "Private", except the backstory's read-only state); `.blocked` / `.blocked-reason` (a disabled button keeping its label and cost, the reason beside it); `.tabs` / `.tab` (underline tabs); `.list-pane` (the archives and editor list + detail layout) and `.next` (the "what happens next" bar) live in `style.css`, not in their components (2026-11-20 cleanup); `dialog.dialog` (`--mf` border, 3px top; a full-screen sheet on phones, see [pickers-and-info.md](pickers-and-info.md)). Form fields: a dark box with an `--edge` outline that turns lilac in use. Colour pickers (`input[type='color']`) are drawn the same way, as a swatch of the colour instead of browser chrome; `.colour-input` joins a hex box and its picker into one control (2026-11-21).
- **Buttons** (the prototype's): lilac uppercase text in an `--edge` outline that turns lilac with a faint tint on hover. `.primary` (filled lilac, one main action per view), `.danger` (`--danger` text and outline, tinted on hover), `.quiet` (a text action), `.small`. Disabled buttons go dim and keep their label. The global rules are in `:where()`, so a component's own button rule always wins.
  - **`.option` keeps the old terminal look:** `[ like this ]` in lilac, turning into `> like this <` in rose when hovered or selected. Only on the home and login screens; it resets every part of the button look so those screens stay as they were.
- **"Are you sure?"** uses the site's own dialog: `confirmAction(message, { confirmLabel, danger })` in `src/confirm.ts` (a promise of true/false), drawn by `ConfirmDialog.vue` in `App.vue` in the shared `dialog.dialog` frame: a `.dialog-head` ("Are you sure?"), the message in the body, and a foot with `Cancel` (`.quiet`) and the confirm button (`.primary`, or `.danger` when `danger`). Destructive questions start on Cancel. Nothing uses `window.confirm`.
