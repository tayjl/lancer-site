Option A · Archive

The same list + detail layout as the Archives. Quick to hop between many short entries, and it looks like the rest of the site. Long stories get a narrower reading column on desktop.

Option B · Library

A landing page of entry cards with the newest entry featured, then a dedicated reading page for each entry. The most inviting option and the best reading experience; less dense once there are many entries. (Covers need image uploads, which aren’t built yet.)

Option C · Codex

An encyclopedia: a compact A-Z index and entries with a facts box and links between entries. Scales best to a big setting bible and suits places and factions; the plainest option for short stories.

GM editor (all options)

How a GM writes an entry; the same for every option. Option C adds the Facts rows.
